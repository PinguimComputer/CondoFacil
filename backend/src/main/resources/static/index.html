Como funciona

O backend chama sp_registrar_pagamento. A procedure abre transação, bloqueia a cobrança, valida o saldo e confirma com COMMIT. Em caso de erro, executa ROLLBACK. A trigger atualiza o status e registra a entrada financeira.
